# ChakrView Unified Conversational Intelligence v1.0

Welcome to ChakrView v1.0, the indigenous hybrid conversational intelligence release.

## Features
- **Indigenous Neural Brain:** ChakrMicro v0.1 architecture trained from first principles.
- **Hybrid Memory Subsystem:** Built-in session working memory and structured semantic store.
- **Multilingual Support:** English, Devanagari Hindi, Roman Hindi, and Hinglish.
- **Local Execution:** 100% CPU-executable locally without external dependencies or cloud APIs.

## Quickstart
```bash
python -m chakrview chat --checkpoint releases/v1.0_unified_conversational_intelligence/chakrview_v011_model.pt
```

## Session Commands
- `/info`: Displays active model parameters, context ceiling, and session metadata.
- `/memory`: Displays currently stored conversational facts and entities.
- `/reset`: Flushes conversational history and resets working memory.
