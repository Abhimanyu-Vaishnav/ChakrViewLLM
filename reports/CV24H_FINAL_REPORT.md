## 4. Human-Reviewed Conversational Sampling

Below are verbatim outputs generated by the neural model under test:

### Example 1: Greeting & Persona
- **User:** `Hello! Who are you?`
- **Model Output:** `Hello! Ready to help with reachable ties for your roundation via first end].`
- *Human Review:* The model correctly identifies the conversational register, issues an appropriate greeting (*"Hello! Ready to help..."*), but drifts syntactically due to small pretraining token exposure.

### Example 2: Code Inquiry
- **User:** `Can you help me write a Python function?`
- **Model Output:**
  ```python
  def get_attr(obj, **kwargs):
      return __init__(self)
  ```
- *Human Review:* Demonstrates strong Python code syntax recognition (valid Python markdown formatting, `def` keyword, parameter signature, indentation), though the function body is nonsensical.

### Example 3: Factual Question
- **User:** `What is the boiling point of water at standard pressure?`
- **Model Output:** `The passage highlights that each other.`
- *Human Review:* Fails to answer the factual query; shows classic hallucination of expository text phrases from the STEM training corpus.
