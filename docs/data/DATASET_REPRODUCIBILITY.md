## 1. Reproducibility Standard

To guarantee scientific reproducibility across training experiments, all datasets must be evaluable against clear reproducibility tiers:
- `GENERATION_DETERMINISTIC`: Source code implementation logic and random seeds are fully deterministic.
- `SPLIT_DETERMINISTIC`: Dataset partitioning and shuffling procedures are deterministic and reproducible.
- `BIT_EXACT_VERIFIED`: Regenerated bytes have been independently executed and verified byte-for-byte against the stored repository artifact.
- `REPRODUCIBILITY_UNVERIFIED` / `REPRODUCIBILITY INCOMPLETE`: Insufficient evidence or missing generator scripts prevent independent execution.

Documenting deterministic generation logic does not automatically prove bit-exact reproduction until independent byte-level comparison is executed. Any dataset whose exact byte stream or record sequence cannot be independently regenerated from documented inputs is flagged as `REPRODUCIBILITY INCOMPLETE`.
