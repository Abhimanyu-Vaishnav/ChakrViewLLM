## 1. Release Purpose & Qualification

This manifest qualifies **ChakrView v0.5.0** as an **Experimental Research Preview**, preparing the system for an honest founder-led acceptance decision.

### Scientific Scope Definition
ChakrView v0.5.0 is **NOT** a general-purpose conversational LLM, an autonomous general reasoner, or a universally factually correct assistant. It is a research artifact demonstrating the feasibility of combining a compact from-scratch neural core with a governed cognitive architecture, deterministic relational verification, hardware-adaptive budgeting, and durable task recovery.

### Subsystem Boundaries & Architecture
ChakrView v0.5.0 explicitly separates its distinct architectural subsystems:

1. **From-Scratch Neural Core (`ChakrMicro`)**:
   - 3,443,136 parameters ($L=6, d=384, H=6, V=4096$), initialized with canonical seed 42.
   - Operates strictly on CPU via local autoregressive inference.
   - **Current Limitations**: Small parameter capacity leads to loop collapse, repetition, and template leakage under open-ended free generation. Passing deterministic unit tests does not imply neural intelligence or general reasoning. Lower repetition or token diversity does not equate to reasoning quality.
2. **Governed Cognitive Runtime & Relational Grounding**:
   - Deterministic linguistic parsing (`CompositionalSentenceParser`, `TextNormalizer`) extracting canonical triples `(Subject, Relation, Object)`.
   - Explicit multi-hop transitivity path evaluation over relational spaces.
   - Deterministic realizer (`LanguageRealizer`) mapping structured epistemic decisions to natural language.
   - **Operational Distinction**: The system answers factually when governed cognitive rules find explicit grounded evidence; open-ended queries fall back to honest abstention (`ABSTAIN`) or bounded neural generation. Rule-based verification paths do not confer universal factual correctness to ungrounded or neural-generated outputs.
3. **Working Memory & Evidence Precedence**:
   - Bounded task-scoped memory (`WorkingMemory2`) ensuring zero durable memory pollution.
   - Timestamped evidence precedence: new verified external evidence strictly overrides stale internal beliefs.
4. **Tool Invocation, Hierarchical Planning & Task Orchestration**:
   - DAG goal decomposition into dependency-aware subgoals (`RETRIEVE`, `VERIFY`, `SYNTHESIZE`).
   - Dynamic replanning on intermediate step failure.
5. **Durable Local Execution Recovery**:
   - Disk-backed execution journaling (`DurableExecutionJournal`, `DurableChunkedExecutor`).
   - Atomic disk writes, SHA-256 tamper detection, schema validation, and transparent process restart resumption.
6. **Hardware Discovery & Resource Budgeting**:
   - Host profiling of CPU cores, system RAM, GPU, and VRAM.
   - Resource governance: `AVAILABILITY != PERMISSION != REQUIREMENT` (strict memory caps, yielding to interactive user activity).
   - Dynamic profile selection (`CPU_ONLY`, `BALANCED`, `CPU_HIGH_MEMORY`, `LOW_RESOURCE`).
7. **Benchmarking & Reproducibility Tooling**:
   - Strict evaluation harness, deterministic seed control, and test automation.
8. **Designed / Unverified Distributed Execution**:
   - Multi-node federation, network mesh, and wire transport exist as designed prototypes or unit mocks only (`DESIGNED_ONLY` / `NOT_VERIFIED`). They are explicitly deferred and not claimed as verified physical capabilities.

### Epistemic Outcomes & Confidence Semantics
Runtime responses produce distinct terminal outcomes:
- `ANSWER`: Factual relational evidence or verified knowledge path resolved unambiguously.
- `ABSTAIN`: Insufficient evidence, unknown entity, or ungrounded novel premise. The system explicitly refuses to hallucinate.
- `REPORT_CONFLICT`: Contradictory evidence detected across sources; conflict is reported honestly.
- `FAILED`: Step or task execution could not be completed within allocated retries.
- `FALLBACK`: Deterministic cognitive fallback invoked when neural confidence or parse grounding is absent.

> [!NOTE]
> **Interpretation of Confidence Values**: Reported confidence values (e.g. `0.90` for direct relational match, `0.40` for conflict, `0.00` for unknown/abstain) are **deterministic heuristic epistemic markers** reflecting verification status and evidence provenance. They are **NOT** calibrated Bayesian probabilities or statistical model likelihoods. Calibration has not been demonstrated and must not be inferred.

## 4. Honest Scientific Boundaries & Explicit Limitations

To maintain absolute scientific rigor, the following operational boundaries are explicitly defined:

- **Experimental Research Preview Status**: ChakrView v0.5.0 is an experimental preview. Passing automated test suites does not constitute founder acceptance or imply general intelligence.
- **One Brain, Adaptive Strategy**: Hardware differences change execution strategy, batching, chunking, and device scheduling — NOT cognitive identity or model weights.
- **GPU Acceleration Scope**: GPU support is available for supported operations when real benefits exist; CPU fallback is automatic. The system does NOT claim full GPU acceleration across every legacy symbolic component.
- **Distributed Computing Roadmap**: Multi-node network coordination, peer mesh, and wire transport exist only as designed prototypes and unit mocks (`DESIGNED_ONLY`). Physical multi-machine cluster execution is deferred to post-v0.5.0.
- **Neural Learning Boundary**: Candidate learning records and working memory beliefs are non-parametric cognitive structures. They are NOT learned neural weights; canonical model weights remain strictly frozen ($\Delta W = 0$).
- **Language Scope Limitations**: Language understanding handles English and common Hinglish conversational patterns. Bengali, Tamil, and other regional language acquisition remain roadmap items.
- **Not an AGI or General LLM**: ChakrView is NOT an Artificial General Intelligence, an autonomous driving agent, a ChatGPT equivalent, or an unrestricted open-ended conversational bot.
- **Neural Generation Limitations**: Spontaneous, open-domain long-form text generation remains constrained by the microscopic 3.44M parameter baseline. Token diversity or reduced repetition does not equal reasoning quality.
- **Scoped Generalization**: Relational reasoning, planning, and semantic grounding operate robustly under defined tasks and structured evidence, but broad open-world zero-shot transfer across completely disjoint open vocabularies is not claimed.
- **Heuristic Confidence**: Confidence values indicate evidence verification source provenance, not statistical calibrated probability.
- **Production Baseline Stability**: No continuous unconstrained self-learning is applied to the production baseline weights ($\Delta W = 0$ is strictly preserved).
