## 3. Cognitive & Semantic Capabilities in v0.5.0

ChakrView v0.5.0 unifies the neural representation base with modular cognitive layers under a **One Cognitive Brain + Hardware-Adaptive Execution** architecture:

1. **Hardware-Adaptive Resource Governance**:
   - Runtime discovery of host CPU, RAM, GPU, VRAM, and OS capabilities.
   - Dynamic profile selection (`CPU_ONLY`, `CPU_HIGH_MEMORY`, `GPU_ACCELERATED`, `GPU_MEMORY_CONSTRAINED`, `IGPU_SHARED_MEMORY`, `LOW_RESOURCE`, `BALANCED`).
   - Strict resource containment: `RESOURCE AVAILABILITY != PERMISSION != REQUIREMENT` (minimum sufficient allocation; yields to interactive user workloads).
   - Task sizing: auto-detects single-pass fit vs. chunked execution with checkpointed progress (`Node/Chunk Failure != Task Failure`).
2. **Relational Semantic Grounding & Language Understanding Foundation**:
   - Indigenous input normalization (`TextNormalizer`) preserving verbatim input and proper nouns while correcting typos and transliterations.
   - Compositional sentence understanding (`CompositionalSentenceParser`) detecting grammatical mood, speech act, negation, tense, and question targets across English and Hinglish.
   - Maps varied surface linguistic expressions (e.g., active, passive, synonyms, inverted word order) into structured canonical relational triples `(Subject, Relation, Object)`.
   - Clear architectural separation between built-in verified knowledge, memory retrieval, deterministic realizer, and neural representations.
   - Governed candidate learning ledger (`CandidateLearningLedger`) recording user-asserted facts as governed candidate records with provenance and `PENDING_VERIFICATION` status without altering canonical neural weights ($\Delta W = 0$).
3. **Multi-Hop Transitivity Reasoning**:
   - Evaluates chained multi-hop paths ($E_1 \to E_2 \to E_3 \to E_4$) over relational spaces without lookup tables.
4. **Semantic Cognitive Coupling**:
   - Links grounded relational representations to downstream reasoning decisions, enabling evidence-based answers, contradiction detection, and calibrated abstention.
5. **Hierarchical Planning & Recovery**:
   - Decomposes high-level objectives into dependency-aware subgoals (`RETRIEVE`, `VERIFY`, `SYNTHESIZE`).
   - Automatically detects step-level failures and dynamically triggers replanning.
6. **Memory & Evidence Governance**:
   - Strict precedence of **new verified external evidence** over stale internal memory beliefs.
   - Bounded task-scoped working memory (`WorkingMemory2`) ensuring zero durable memory pollution.

## 4. Honest Scientific Boundaries & Explicit Limitations

To maintain absolute scientific rigor, the following operational boundaries are explicitly defined:

- **One Brain, Adaptive Strategy**: Hardware differences change execution strategy, batching, chunking, and device scheduling — NOT cognitive identity or model weights.
- **GPU Acceleration Scope**: GPU support is available for supported operations when real benefits exist; CPU fallback is automatic. The system does NOT claim full GPU acceleration across every legacy symbolic component.
- **Distributed Computing Roadmap**: While decentralized peer assistance and wire transport foundations exist as research prototypes, permission-based multi-node execution, node-failure recovery, and resumable cluster coordination remain future roadmap work and are NOT claimed as production-ready in v0.5.0.
- **Neural Learning Boundary**: Candidate learning records and working memory beliefs are non-parametric cognitive structures. They are NOT claimed as learned neural weights; canonical model weights remain strictly frozen ($\Delta W = 0$).
- **Language Scope Limitations**: Language understanding handles English and common Hinglish conversational patterns. Bengali, Tamil, and other regional language acquisition remain roadmap items.
- **Not an AGI or General LLM**: ChakrView is NOT an Artificial General Intelligence, an autonomous driving agent, a ChatGPT equivalent, or an unrestricted open-ended conversational bot.
- **Limited Natural Language Generation**: Spontaneous, open-domain long-form text generation remains constrained by the microscopic 3.44M parameter baseline.
- **Scoped Generalization**: Relational reasoning, planning, and semantic grounding operate robustly under defined tasks and structured evidence, but broad open-world zero-shot transfer across completely disjoint open vocabularies is not claimed.
- **Hardware Validation Scope**: Physical 28nm-era silicon tape-out validation has not yet occurred; the architecture is evaluated across commodity CPU and GPU environments.
- **Production Baseline Stability**: No continuous unconstrained self-learning is applied to the production baseline weights ($\Delta W = 0$ is strictly preserved).
