## 1. Architectural Routing Contract

The runtime integrates all previously developed capabilities into an explicit, transparent, multi-tier routing architecture:

```
[ User Input + Optional Context / Retrieval Query ]
                         │
                         ▼
             [ CognitiveRouter.classify_route ]
                         │
       ┌─────────────────┼────────────────────────┬───────────────────┐
       ▼                 ▼                        ▼                   ▼
 [POINTER_COPY]   [SLOT_EXTRACTION]      [KNOWLEDGE_RETRIEVAL]   [DIRECT_CHAT]
       │                 │                        │                   │
  TokenTrie /      EvidenceExtractor       HybridRetriever      ChakrMicro Neural
 Pointer Head    (Regex / Deterministic)   (BM25 + Bi-Encoder)  Autoregressive Core
       │                 │                        │                   │
       └─────────────────┴───────────┬────────────┴───────────────────┘
                                     ▼
                          [ GroundedResponse ]
                      - answer: str
                      - component_origin: ComponentOrigin
                      - route_decision: RouteDecision
                      - is_supported: bool
                      - support_explanation: str
                      - retrieved_chunks: List[dict]
                      - latency_ms: float
```

## 2. Component Origin Hierarchy & Truthful Attribution

Every output generated by `GroundedSessionAdapter` and `InteractiveModelSessionCoordinator.generate_grounded_turn` is tagged with an immutable `ComponentOrigin`:

| Origin Enum | Description | Grounding Level |
|---|---|---|
| `NEURAL_CORE` | Autoregressive generation from the 3.4M ChakrMicro baseline. Unconstrained open-ended text. | Context-conditioned when context provided; otherwise prior parametric memory. |
| `NEURAL_POINTER` | Unconstrained pointer copy attention directly selecting token positions from context. | Directly bound to context token positions. |
| `CONSTRAINED_TRIE` | TokenTrie constrained pointer decoding over explicit candidate token spans. Guarantees valid UTF-8 sequences. | Bound to explicit context candidate spans. |
| `DETERMINISTIC_EXTRACTOR` | Exact rule-based slot extraction with unit awareness and contradiction detection. | Verified exact context span citations. |
| `HYBRID_RETRIEVER` | BM25 lexical + bi-encoder reranked chunk retrieval. | Document chunk citations with retrieval scores. |
| `FALLBACK_POLICY` | Explicit safe abstention when evidence is missing, conflicting, or below confidence threshold. | Unanswerable / abstain. |

---

## 3. Failure & Fallback Guarantees
1. **Empty / Malformed Input:** Returns `FALLBACK_POLICY` or abstention without throwing exceptions or executing unbounded neural loops.
2. **Missing Evidence:** Returns explicit *"Not mentioned in context."* rather than hallucinating plausible facts.
3. **Conflicting Evidence:** Returns *"Conflicting evidence detected in context: values found include ['X', 'Y']."*
4. **Context Overflow:** Safely truncates context to `MAX_CONTEXT_WINDOW` (512 tokens).
