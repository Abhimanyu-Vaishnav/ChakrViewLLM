# Certified Deployment Platforms and Python Versions

## 1. Supported Environments
- Certified Python runtimes: Python 3.10, Python 3.11, Python 3.12, Python 3.13, and Python 3.14.
- Deprecated / Unsupported versions: Python 3.8 and Python 3.9 are strictly unsupported.
- Supported operating systems: Windows 11, Ubuntu 22.04 LTS, Ubuntu 24.04 LTS, and macOS 14+.
