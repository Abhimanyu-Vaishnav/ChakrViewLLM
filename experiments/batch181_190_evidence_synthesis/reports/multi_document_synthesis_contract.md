# Multi-Document Evidence Synthesis Contract: Batch 187
## Traceable Claim-Level Provenance & Safe Neural Pointer Attribution

### 1. Architectural Pipeline
The multi-document synthesis workflow connects:
1. **Hybrid Retrieval (`HybridReranker`):**
   - Stage 1: BM25 candidate generation (high recall across ingested corpus).
   - Stage 2: Learned bi-encoder re-ranking (dense semantic scores).
2. **Evidence Assembly (`MultiDocumentEvidenceAssembler`):**
   - Deduplication by cryptographic content hash (`provenance_hash`).
   - Cross-document contradiction detection (`has_conflicts`, `conflicting_values`).
   - Context budget constraint ($\le 380$ context tokens to fit within ChakrMicro's $512$ limit).
3. **Pointer Decoding (`decode_pointer_beam` / `decode_pointer_greedy`):**
   - Context mask strictly covers the assembled multi-document text span.
   - Outputs token attribution per step: `copy`, `vocab`, or `mixture`.
4. **Deterministic Span Verification (`EvidenceVerificationWorker`):**
   - The candidate answer generated by the neural core is cross-referenced against the assembled evidence bundle.
   - If the neural core outputs a hallucinated token or ungrounded entity, the verifier rejects the answer and initiates safe abstention.

### 2. Attribution Hierarchy & Component Guarantees
| Output Category | Responsible Component | Attribution Rule |
| :--- | :--- | :--- |
| **Grounded Copy** | `neural_pointer` | Copied from context span via `ChakrPointerHead` ($g > 0.6$) and verified against source bundle. |
| **Grounded Vocabulary** | `neural_core` | Generated from base vocabulary distribution ($g < 0.2$) supported by context. |
| **Deterministic Extraction** | `deterministic_extractor` | Slot extracted directly via regex/rule-based parser from verified source chunk. |
| **Contradiction Abstention** | `fallback_policy` | Multiple distinct facts found across documents; engine refuses to arbitrate without authority. |
| **Missing Evidence Abstention** | `fallback_policy` | Target relation absent from all retrieved chunks; engine emits explicit abstention string. |
